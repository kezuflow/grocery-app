# Payment-method logos

These SVGs are the payment-method marks rendered by the authenticated PayMongo dashboard on
2026-09-21. They identify methods in checkout; possessing an asset does not activate its payment
channel. Availability remains controlled by the verified provider capability and application code.

The exported dashboard set contains QR Ph, GCash, GrabPay, Maya, ShopeePay, Google Pay,
Visa/Mastercard, BDO, BPI, Landbank, Metrobank, RCBC, UnionBank and BillEase. BillEase is retained as
an asset only and is not presented by checkout until separately approved and enabled.
