# Third-party animation assets

`payment-success.lottie` is the “Payment Successful” animation by Fahmi from
[LottieFiles](https://lottiefiles.com/free-animation/payment-successful-5uXFkB4jix).
It is distributed under the
[Lottie Simple License](https://lottiefiles.com/page/license).

The file is self-hosted so checkout completion does not depend on a third-party
asset request. `dotlottie-player.wasm` is the matching runtime distributed by
the installed `@lottiefiles/dotlottie-web` package and is also served locally.
